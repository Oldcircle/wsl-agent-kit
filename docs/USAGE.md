# 日常使用教程(给使用者)

## 打开与关闭

- **打开**:双击桌面「AI 助手」。黑色窗口里出现输入框就绪了,直接打中文。
- **关闭**:输入 `/quit` 或直接关窗口。
- 万一快捷方式丢了:开始菜单 →「AI 办公助手」里都有;或者重新运行里面的「修复或升级」,图标会补回来。

## 心智模型(30 秒理解它)

它不是聊天机器人,是个**会自己动手的助理**:能读写文件、上网查资料、跑工具。你只管用中文布置任务和验收。它的「办公桌」就是你 Windows 文档里的 **AI工作区** 文件夹(桌面有快捷方式),你的桌面、下载文件夹它也直接够得着。

**所有入口默认都站在工作区**:双击图标、`ai` 命令自不必说;就算你自己开 Ubuntu 终端直接敲 `opencode`/`claude`,只要开终端时在家目录,也会被自动带到 `~/workspace`——所以无论从哪儿启动,AI 都遵守同一套工作区规矩(AGENTS.md)。

第一次使用建议先说:「介绍一下这个工作区,你能帮我做什么?」

## 各场景开场白(直接照抄)

**文件整理/处理**
- 「看看我下载文件夹里最近的 20 个文件,按类型帮我归类,先给我方案再动手」
- 「桌面有个 商品清单.xlsx,把重复行去掉、按销量排序,另存一份『-已清洗』版」
- 「把收件箱里 5 个 Word 的内容要点合并成一页纸摘要」

**文案撰写**
- 「写一篇小红书:主题 XX,人群 XX,卖点 XX。按模板来,给两版」
- 「把 2-文案 里上周那篇公众号改成 60 秒抖音口播稿」
- 改稿:「第二版方向对,但开头太硬,口语一点,再给 3 个标题」

**调研**
- 「调研一下 2026 年 XX 行业的头部品牌和它们的打法,按调研报告模板输出,来源要可点」
- 「帮我核实这个说法是不是真的:XXX。至少三个来源」

**短视频分析**
- 先把视频文件放到桌面或下载文件夹,然后:「下载文件夹里的 XXX.mp4 是条爆款,转写并按模板拆解,最后套用它的公式给我写一条我们产品的口播稿」
- 只有链接没文件时:先在手机端用抖音自带「保存本地」或电脑端下载工具拿到 mp4。

**批量活**
- 「把下载文件夹的『照片』里 300 张图按拍摄日期建文件夹归档,先演示 3 张」

## AI 控制台(管理面板)

双击桌面「**AI 控制台**」会打开一个小窗口,列出全部 9 个 AI 助手和状态:

- **双击某一行 = 启动它**(在新终端窗口打开,不影响正在聊的那个)
- 「★ 设为默认」:以后双击「AI 助手」就是它
- 「安装选中的」:灰色未装的,点这里现场加装
- 「全部升级」:把装了的 AI 助手都更新到最新版
- 「体检 / 排障」:出问题先点它,会生成一份诊断报告(Key 已打码),发给安装人即可
- 「打开 AI 工作区」「配置 AI 服务」「使用教程」:常用入口

终端党等价物:`ai menu`(↑↓ 选择启动)、`ai list`、`ai use <名字>`、`ai update`、`ai doctor`。

## 小命令速查(在 Ubuntu 终端里用)

| 命令 | 作用 |
|------|------|
| `ai` | 启动默认 AI 助手(等于双击桌面图标) |
| `ai claude` / `ai kimi` / `ai hermes` … | **本次**临时换一个 agent 开工 |
| `ai use kimi` | **换默认**:以后双击图标就是它 |
| `ai list` | 看装了哪些 agent、当前默认是谁 |
| `ai-config` | 换 AI 服务商 / 重填 Key |
| `ai-video 文件` | 手动把视频/音频转成文字稿(AI 通常会自己调用) |
| `ai-install 名字` | 加装 agent,如 `ai-install hermes`(可一次写多个) |
| `ai update` | 把已装的 agent 全部升级到最新版 |
| `ai doctor` | 体检:网络、Key、配置一次查清,报告存在 8-归档 |
| `ai help` | 看全部命令 |

## 多个 agent 怎么理解

装了几个 agent = 同一个「办公室」里有几位助理,**文件、模板、规矩(AGENTS.md)全共享**,只是聊天界面和背后的模型不同:

- **OpenCode**:默认主力,界面是英文的,不影响你全程用中文对话。
- **Claude Code**:你的 Key 是 DeepSeek/GLM/Moonshot 家的话,**配置时已自动接好**,控制台里双击就能用;向导只是问"默认用谁打开"。
- **Kimi Code**:中文界面;买了 Kimi 会员时的默认选择(登录制,首次 OAuth 一次即可)。
- **Hermes(爱马仕)/ OpenClaw(小龙虾)**:常驻助理型,会记住你、能配置成主动干活,属于进阶玩法;第一次用建议让安装人陪你设置。OpenClaw 别随便装社区技能(有安全争议),消息通道功能在国内基本用不上,本机对话模式即可。

想换默认:`ai use <名字>`(或 `ai-config` 重新走一遍);想临时用某个:`ai <名字>`。

## 怎么看 AI 做出来的东西(全部原生,不用学新软件)

工作区**就是你 Windows 文档里的一个普通文件夹**(`文档\AI工作区`),桌面「**AI 工作区**」快捷方式直达。里面按序号排好了:

| 文件夹 | 放什么 |
|--------|--------|
| 1-收件箱 | 你要交给 AI 处理的文件,拖进来就行 |
| 2-文案 | AI 写好的文案 |
| 3-调研 | 调研报告 |
| 4-短视频 | 视频转写稿和拆解报告 |
| 5-文件处理 | AI 整理/转换过的表格和文档(原文件不动) |
| 6-笔记 | 长期笔记;「我的偏好.md」记着你的习惯,AI 每次开工先读 |
| 7-模板 | 各类产出的模板,可以按自己口味改 |
| 8-归档 | AI 从不删文件,过时的都挪到这 |

看文件:

- Word/Excel/PPT → 双击,Office/WPS 打开;视频 → 双击,系统播放器;图片/PDF → 双击
- 报告类文档 AI 会**同时给一份 Word 版(.docx)**,双击就能看、能直接发给同事
- **Markdown(.md 文件,AI 的工作稿)**:Windows 11 可以用记事本打开;想看排版好的效果,装免费的 Obsidian(安装时可选,装了会自动把 AI 工作区设成它的仓库)
- 要发到平台的文案,AI 会同时存一份 `-纯文本.txt`,双击 → Ctrl+A → Ctrl+C 直接粘去小红书/公众号
- 给 AI 递文件:直接把文件拖进「AI 工作区\1-收件箱」(或放桌面/下载,AI 都够得着)

分工一句话:**和 AI 说话用「AI 助手」,看东西开「AI 工作区」文件夹(或 Obsidian)**。

## 这些 AI 自带的界面是怎么回事?

本安装包**不套壳**:装的都是各家官方原版,`ai` 只是帮你记住默认那个。所以:

- 在 Ubuntu 终端里直接输 `opencode`、`claude`、`kimi`、`hermes`,用的就是官方原生界面,各家的全部功能(斜杠命令、主题、快捷键)一样不少;
- 其中几家还有**官方图形版**,想要「不像黑窗口」的体验可以另装:Qwen Code Desktop、Hermes Agent 桌面版、Goose Desktop(以上装在 Windows 原生侧),OpenClaw 则自带本地网页控制台;聊天类还可以配 Cherry Studio(开源客户端,不是 agent);
- **注意**:这些图形版打开「文档\AI工作区」里的文件没问题(工作区本来就在 Windows),但它们**不遵守**我们的工作规范(AGENTS.md 的模板流程、删除先确认等)。所以干活推荐用桌面「AI 助手」,图形版当补充的聊天窗口。

## 验收习惯(重要)

- 它做完会汇报「做了什么、文件在哪」;**动了重要文件后自己抽查一眼**。
- 它删除/覆盖文件前会先列清单问你——没看懂清单就别答应。
- 产出内容涉及事实和数字时,让它「附来源」,点开抽查一两个。

## 常见小问题

- **回答到一半断了**:输入「继续」。
- **想换个话题**:输入 `/clear` 清空上下文再开始(省 token 也更聪明)。
- **中文输入显示怪**:用 Windows Terminal(微软商店免费装)打开 Ubuntu 再输 `ai`,体验最好。
- **它说找不到某文件**:把文件拖进「AI 工作区\1-收件箱」或桌面,再说一遍文件名。
- **想让它记住你的习惯**:直接说「记住:以后文案都不要用感叹号」,它会写进「6-笔记\我的偏好.md」,以后每次都照做。
- **窗口里报错停住了**:按提示输入 `ai doctor` 体检,或拍照发给安装人。
