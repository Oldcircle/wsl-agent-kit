# 模板:短视频拆解报告

> 视频:账号名 -《标题》;时长;数据(赞/评/藏,截至日期);转写稿:同目录 `.转写.txt`

## 1. 一句话定位
这条视频是什么类型、打什么人群、靠什么爆。

## 2. 钩子拆解(前 3 秒)
- 原话摘录:
- 用的什么手法(反常识/悬念/利益直给/冲突/身份代入):
- 为什么对目标人群有效:

## 3. 结构逐段拆(带时间轴)
| 时间 | 段落作用 | 原话要点 | 技法 |
|------|---------|---------|------|
| 0:00-0:03 | 钩子 | | |
| … | | | |

## 4. 文案技法清单
逐条列出可复用的写法(句式、转场词、情绪词、数字用法),每条附原句。

## 5. 可复制的套路
把这条视频抽象成一个可套用的公式:钩子公式 + 结构公式 + 结尾公式。

## 6. 套用到我们
用上面的公式,给我们的账号/产品写 1 条同款口播稿初稿(按 templates/抖音口播稿.md 格式)。
