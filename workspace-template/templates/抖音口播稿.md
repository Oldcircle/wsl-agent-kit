# 模板:抖音/视频号口播稿

## 结构(按秒标注)
- **0-3 秒 钩子**:一句话让人不划走(反常识 / 直给利益 / 冲突提问);给 3 个候选
- **3-10 秒 立题**:说清这条视频讲什么、跟观众有什么关系
- **10-40 秒 主体**:2-3 个要点,每个要点 = 一句结论 + 一个例子;要点间加转场词(「更狠的是」「但注意」)
- **最后 5 秒 结尾**:一句总结 + 互动引导(评论区告诉我 / 关注看下集)

## 格式要求
- 全程口语,一句一行,方便照着念;每行 ≤ 20 字
- 标注【停顿】【重音】【画面:xxx】提示位
- 总时长目标 45-60 秒(≈ 220-300 字),超了先砍主体第 3 点

## 自查清单
- [ ] 钩子 3 秒内说完?
- [ ] 通篇有没有「书面语」?(念一遍,不像说话就改)
- [ ] 每个要点有例子吗?
- [ ] 结尾互动是具体问题(不是干巴巴的「你怎么看」)?
