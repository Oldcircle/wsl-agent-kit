# 模板:公众号文章

## 结构
1. **标题**:给 3 候选(利益型 / 好奇型 / 观点型 各一)
2. **导语**(100 字内):场景或痛点切入,末句抛出本文回答的问题
3. **正文**:2-4 个小节,每节小标题;每节 = 观点 + 案例/数据 + 一句小结
4. **结尾**:全文一句话总结 + 引导(在看/转发/留言)
5. **配图位标注**:在文中用「【配图:xxx】」标出建议插图位置和内容

## 自查清单
- [ ] 标题 ≤ 25 字,不做标题党但有信息增量?
- [ ] 每节能独立成立(跳读也能看懂)?
- [ ] 案例是否具体(有人物/数字/前后对比)?
- [ ] 段落 ≤ 4 行(手机阅读),关键句加粗?
- [ ] 结尾引导只有一个动作(不贪多)?
