# 模板:小红书笔记

## 结构
1. **标题**(≤20 字):数字/反差/悬念至少占一样;给 3 个候选
2. **首句钩子**:1 句话让目标人群觉得「在说我」
3. **正文**(300-800 字):分 3-5 个小段,每段一个小标题或 emoji 开头;口语化,像发小红书不像写作文
4. **结尾**:一个互动问题(引评论)+ 一句行动引导
5. **标签**:5-8 个,大词(泛流量)+ 精准词(转化)混配

## 自查清单(写完逐条过)
- [ ] 标题 20 字内且有点开欲?
- [ ] 前两行(封面外露部分)信息量够不够?
- [ ] 有没有具体细节/数字?(空话删掉)
- [ ] 是否口语?(默读一遍,拗口就改)
- [ ] 敏感词自查:医疗功效、绝对化用语(最/第一/百分百)、平台违禁词
- [ ] 标签有没有跟内容强相关的精准词?
